Добавить DLC

Вставь сюда сразу весь список ссылок (Ctrl+V). Порядок важен: part001, part002, part003… От 2 до 100 частей. Сортировка помогает, если номер части указан в имени ссылки; иначе проверь порядок вручную. При заполнении этого списка поле одного ZIP должно быть пустым. Лаунчер скачает части и соберёт ZIP автоматически.

Зеркала загрузки

Каждое зеркало может быть обычным ZIP или отдельным многотомным архивом. В карточке зеркала укажи одну ссылку для обычного ZIP либо 2–100 ссылок на его части. Лаунчер будет скачивать выбранное зеркало целиком, объединять части и сохранять готовый ZIP для ручной установки.
Массовое добавление зеркалПустая строка разделяет источники; внутри одного источника ссылки на части идут построчно
Можно вставить сразу несколько зеркал блоками. В первой строке блока укажи название (или «Название | ссылка»), ниже — ссылку/ссылки. Одна ссылка означает один ZIP; несколько ссылок — части одного ZIP. Старый формат «Название | ссылка» тоже поддерживается.
Порядок зеркал и частей сохранится. Лимит — 20 зеркал и 100 частей на источник.
